# Chromascope: ingredient safety filter and reaction model (research code)

Research code for the Bayesian-Chromascope Hybrid Safety Filter (thesis Section 3.3B) and an exploratory survey-based
reaction model. This folder is standalone: it is not wired into the app backend (`backend/app/core/filter.py` is a
separate, rule-based implementation).

## Data (not in this repository)
The survey CSVs contain real respondents' health data (age, sex, pregnancy status, skin diagnoses) and are kept out of
the public repo by `.gitignore`. Get them from the research team and place them here:

    research/safety-filter/chromascope_real_cleaned.csv          # 64 real survey responses, numeric schema
    research/safety-filter/chromascope_merged_for_training.csv   # real rows + 4,000 synthetic rows (weights: real 1.0, synthetic 0.3)
    research/safety-filter/chromascope_merged_balanced.csv       # above + synthetic rows balancing Dry and Pigmented skin types

`model/chromascope_500_balanced.csv` and `model/cv_results.csv` are generated by the model pipeline. Never commit any CSV.

## Layout
- `model/`: builds the 500-row skin-type-balanced dataset and trains the NumPy neural network (exploratory reaction model).
- `filter/`: safety filter (`safety_filter.py`), test-case generator, tuning and evaluation scripts.
- `filter/cases.json` is the **frozen** test set. Do not regenerate it (do not run `make_cases.py`).

## Run
    pip install -r requirements.txt
    cd model  && python build_dataset_500.py && python train_model.py     # exploratory reaction model, 5-fold CV
    cd ../filter && python tune_and_test.py                                # filter ablation, dev tuning, frozen test

`tune_and_test.py` rescores the test set and rewrites `chosen_thresholds.json` and `test_predictions.json`.

## Results at hand-off (synthetic test cases, labels drafted by the assistant)
- Reaction model (respondent-level 5-fold CV): accuracy ~0.68, F1 (reaction) ~0.40, AUC ~0.69. Below the majority-class
  baseline accuracy (0.794), not the 90% target, and not in the paper.
- Safety filter, 150-case test: accuracy 0.953, kappa 0.917, macro F1 0.946; 30/30 controlled allergen cases Excluded.

## Caveats
- Synthetic rows are not validation data.
- Test labels come from the same Appendix B/C tables as the filter's flag priors, so the test score is circular by design.
- Before reporting in Section 4.4.5, replace the synthetic test cases with the real 60 + 20 cases labeled independently
  by two researchers.
